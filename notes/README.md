# Lab Journal (`notes/`)

This directory belongs to the **project owner** (human lab journal).

> **Agent Rule:** Do **not** create, edit, or overwrite files inside `notes/` unless the owner explicitly asks.

## Suggested Entry Format (`notes/sNN.md`)

After finishing each stage, jot down ~5 lines covering:
1. What surprised you?
2. What broke (and why)?
3. What did the framework (`pydantic-ai`) handle for you vs. hide?
4. Where did the coding agent err, guess, or take a shortcut?
5. What would fail if one piece of the harness were removed?
